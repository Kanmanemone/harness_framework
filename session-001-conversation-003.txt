       16 -## 핵심 기능                                                 
       17 -                                                             
       18 -### 기능 1: YouTube URL 입력 및 댓글 수집                    
       19 -YouTube 영상 URL을 입력하면 해당 영상의 댓글을 자동으로 수집한
          -다.                                                          
       20 -                                                             
       21 -**지원하는 URL 형식:**                                       
       22 -- `https://www.youtube.com/watch?v=VIDEO_ID`                 
       23 -- `https://youtu.be/VIDEO_ID`                                
       24 -- `https://www.youtube.com/embed/VIDEO_ID`                   
       25 -- `https://www.youtube.com/v/VIDEO_ID`                       
       26 -- 위 형식에 추가 쿼리 파라미터(`&t=`, `&list=` 등)가 붙어도 동
          -작                                                           
       27 -                                                             
       28 -**수집 규칙:**                                               
       29 -- 최대 100개 댓글 수집 (YouTube API `maxResults` 상한)       
       30 -- 관련도순(`order=relevance`) 정렬 — 좋아요 많고 답글 많은 의 
          -미 있는 댓글 우선                                            
       31 -- 최상위 댓글만 수집 (대댓글 제외)                           
       32 -- 일반 텍스트(`textFormat=plainText`) 형식으로 가져옴        
       33 -                                                             
       34 -**수용 기준:**                                               
       35 -- 유효한 YouTube URL 입력 시 댓글이 수집되어야 한다          
       36 -- 댓글 수집 중 로딩 상태가 UI에 표시되어야 한다              
       37 -- 수집된 댓글 수가 리포트에 표시되어야 한다                  
       38 -                                                             
       39 -### 기능 2: AI 센티먼트 분석                                 
       40 -수집된 댓글을 Claude AI에 전송하여 센티먼트를 분석한다.      
       41 -                                                             
       42 -**분석 항목:**                                               
       43 -- 전체 요약 (1-2문장)                                        
       44 -- 센티먼트 비율: 긍정/중립/부정 퍼센트 (합계 100%)           
       45 -- 잘하고 있는 점: 최대 5개, 구체적이고 댓글에 근거한 내용    
       46 -- 개선할 점: 최대 5개, 구체적이고 댓글에 근거한 내용         
       47 -- 대표 댓글: 긍정/중립/부정 각 2-3개, 원문 인용              
       48 -                                                             
       49 -**분석 언어:**                                               
       50 -- 댓글이 한국어면 분석도 한국어로, 영어면 영어로. 댓글의 주 언
          -어를 따라간다.                                               
       51 -                                                             
       52 -**수용 기준:**                                               
       53 -- 분석 결과가 JSON 형식으로 파싱 가능해야 한다               
       54 -- 센티먼트 비율의 합계가 100이어야 한다                      
       55 -- 대표 댓글은 실제 수집된 댓글에서만 인용해야 한다           
       56 -- 분석 중 로딩 상태가 UI에 표시되어야 한다                   
       57 -                                                             
       58 -### 기능 3: 리포트 표시                                      
       59 -분석 결과를 시각적으로 보기 좋은 리포트로 렌더링한다.        
       60 -                                                             
       61 -**리포트 구성 (위→아래 순서):**                              
       62 -1. 전체 요약 텍스트                                          
       63 -2. 센티먼트 비율 가로 바 차트 (긍정=녹색, 중립=회색, 부정=빨강
          -)                                                            
       64 -3. "잘하고 있는 점" 카드 (불릿 리스트)                       
       65 -4. "개선할 점" 카드 (불릿 리스트)                            
       66 -5. "대표 댓글" 섹션 (센티먼트별 그룹)                        
       67 -                                                             
       68 -**수용 기준:**                                               
       69 -- 리포트가 화면에 렌더링되어야 한다                          
       70 -- "다른 영상 분석하기" 버튼으로 초기 상태로 돌아갈 수 있어야  
          -한다                                                         
       71 -                                                             
       72 -### 기능 4: API 키 관리                                      
       73 -사용자가 API 키를 입력하고 브라우저에 저장한다.              
       74 -                                                             
       75 -**동작:**                                                    
       76 -- 앱 최초 진입 시 API 키가 없으면 설정 패널이 자동으로 열린다
       77 -- API 키는 localStorage에 저장하여 재방문 시 유지한다        
       78 -- 설정 패널은 접었다 펼 수 있다                              
       79 -- 저장된 키 옆에 체크마크를 표시한다                         
       80 -- 키 입력 필드는 password 타입으로 마스킹한다                
       81 -                                                             
       82 -**수용 기준:**                                               
       83 -- API 키를 입력하고 저장하면 localStorage에 저장되어야 한다  
       84 -- 페이지를 새로고침해도 키가 유지되어야 한다                 
       85 -- 키가 없는 상태에서 분석 버튼을 누르면 에러 메시지가 표시되어
          -야 한다

      169 -## 제약사항                                                  
      170 -- 댓글 수집 상한: 100개 (YouTube API `maxResults` 최대값이 100
          -이며, 비용과 분석 품질의 균형점)                             
      171 -- Claude 컨텍스트: 100개 댓글은 약 10,000~30,000 토큰. Sonnet 
          -의 입력 한도(200K) 내에서 충분히 처리 가능                   
      172 -- Claude 응답 제한: `max_tokens: 2048` (리포트 JSON에 충분한  
          -크기)                                                        
      173 -- YouTube API 일일 할당량: 10,000 유닛 (무료 티어). 1회 분석 =
          - 1 유닛이므로 하루 최대 ~10,000회 분석 가능                  
      174 -- localStorage 용량: API 키 2개 저장에 ~200바이트. 브라우저 lo
          -calStorage 한도(5MB)와 무관

       16 +## 핵심 기능                                                  
       17 +                                                              
       18 +### 기능 1: YouTube URL 입력 및 댓글 수집                     
       19 +YouTube 영상 URL을 입력하면 해당 영상의 댓글을 자동으로 수집한
          +다.                                                           
       20 +                                                              
       21 +**지원하는 URL 형식:**                                        
       22 +- `https://www.youtube.com/watch?v=VIDEO_ID`                  
       23 +- `https://youtu.be/VIDEO_ID`                                 
       24 +- `https://www.youtube.com/embed/VIDEO_ID`                    
       25 +- `https://www.youtube.com/v/VIDEO_ID`                        
       26 +- `https://www.youtube.com/shorts/VIDEO_ID`                   
       27 +- 위 형식에 추가 쿼리 파라미터(`&t=`, `&list=`, `&index=` 등) 
          +가 붙어도 동작                                                
       28 +- `http://` (비보안)도 허용 — `https://`와 동일하게 처리      
       29 +- URL 앞뒤 공백은 자동으로 trim                               
       30 +                                                              
       31 +**지원하지 않는 입력:**                                       
       32 +- 영상 ID만 입력 (예: `dQw4w9WgXcQ`) — URL 형식이 아니므로 거 
          +부. 에러 메시지에 올바른 형식 안내 포함.                      
       33 +- 채널 URL, 재생목록 URL — 영상 URL만 지원                    
       34 +                                                              
       35 +**수집 규칙:**                                                
       36 +- 최대 100개 댓글 수집 (YouTube API `maxResults` 상한)        
       37 +- 관련도순(`order=relevance`) 정렬 — 좋아요 많고 답글 많은 의 
          +미 있는 댓글 우선                                             
       38 +- 최상위 댓글만 수집 (대댓글 제외)                            
       39 +- 일반 텍스트(`textFormat=plainText`) 형식으로 가져옴         
       40 +                                                              
       41 +**수용 기준:**                                                
       42 +- 유효한 YouTube URL 입력 시 댓글이 수집되어야 한다           
       43 +- 댓글 수집 중 로딩 상태가 UI에 표시되어야 한다               
       44 +- 수집된 댓글 수와 전체 댓글 수가 리포트 상단에 표시되어야 한 
          +다 (예: "100개 댓글 분석 (전체 1,523개 중)")                  
       45 +                                                              
       46 +### 기능 2: AI 센티먼트 분석                                  
       47 +수집된 댓글을 Claude AI에 전송하여 센티먼트를 분석한다.       
       48 +                                                              
       49 +**분석 항목:**                                                
       50 +- 전체 요약 (1-2문장)                                         
       51 +- 센티먼트 비율: 긍정/중립/부정 퍼센트 (합계 100%)            
       52 +- 잘하고 있는 점: 최대 5개, 구체적이고 댓글에 근거한 내용     
       53 +- 개선할 점: 최대 5개, 구체적이고 댓글에 근거한 내용          
       54 +- 대표 댓글: 긍정/중립/부정 각 2-3개, 원문 인용               
       55 +                                                              
       56 +**분석 언어:**                                                
       57 +- 댓글이 한국어면 분석도 한국어로, 영어면 영어로. 댓글의 주 언
          +어를 따라간다.                                                
       58 +                                                              
       59 +**수용 기준:**                                                
       60 +- 분석 결과가 JSON 형식으로 파싱 가능해야 한다                
       61 +- 센티먼트 비율의 합계가 100이어야 한다 (아니면 클라이언트에서
          + 정규화)                                                      
       62 +- 대표 댓글은 실제 수집된 댓글에서만 인용해야 한다            
       63 +- 분석 중 로딩 상태가 UI에 표시되어야 한다                    
       64 +                                                              
       65 +### 기능 3: 리포트 표시                                       
       66 +분석 결과를 시각적으로 보기 좋은 리포트로 렌더링한다.         
       67 +                                                              
       68 +**리포트 구성 (위→아래 순서):**                               
       69 +1. 리포트 헤더: 분석된 댓글 수 표시 (예: "100개 댓글 분석 (전 
          +체 1,523개 중)")                                              
       70 +2. 전체 요약 텍스트                                           
       71 +3. 센티먼트 비율 가로 바 차트 (긍정=녹색, 중립=회색, 부정=빨강
          +) + 각 비율 숫자 레이블                                       
       72 +4. "잘하고 있는 점" 카드 (불릿 리스트)                        
       73 +5. "개선할 점" 카드 (불릿 리스트)                             
       74 +6. "대표 댓글" 섹션 (센티먼트별 그룹, 각 댓글에 센티먼트 뱃지 
          ++ 작성자 표시)                                                
       75 +7. 하단: "다른 영상 분석하기" 버튼                            
       76 +                                                              
       77 +**수용 기준:**                                                
       78 +- 리포트가 화면에 렌더링되어야 한다                           
       79 +- 리포트가 표시될 때 fade-in 애니메이션이 적용되어야 한다     
       80 +- "다른 영상 분석하기" 버튼 클릭 시 URL 입력 필드가 비워진 채 
          +로 초기 상태로 돌아가야 한다                                  
       81 +- 리포트 상태에서도 상단의 URL 입력 필드와 설정 기어 아이콘은 
          +보여야 한다 (다른 영상을 바로 분석할 수 있도록)               
       82 +                                                              
       83 +### 기능 4: API 키 관리                                       
       84 +사용자가 API 키를 입력하고 브라우저에 저장한다.               
       85 +                                                              
       86 +**동작:**                                                     
       87 +- 앱 최초 진입 시 API 키가 없으면 설정 패널이 자동으로 열리고,
          + 안내 메시지가 표시된다

       89 +- 설정 패널은 헤더 우측 기어 아이콘으로 접었다 펼 수 있다     
       90 +- 키 입력 필드는 password 타입으로 마스킹한다                 
       91 +- 키가 저장된 상태에서는 마스킹된 값(예: `sk-ant-...7f3d`)이  
          +표시되어 설정 여부를 확인할 수 있다                           
       92 +- "저장" 버튼 클릭 시 키가 localStorage에 저장되고, 설정 패널 
          +이 자동으로 접힌다                                            
       93 +- 각 키 옆에 저장 상태 표시: 저장됨(체크마크) / 미설정(빈 상태
          +)                                                             
       94 +- "키 삭제" 기능: 각 키를 개별적으로 삭제할 수 있다 (localStor
          +age에서 제거)

       96 +**온보딩 안내 (설정 패널 내):**

      273 +    ↓

          +esults=100                                                    
      275 +    ↓                                                         
      276 +API Route (youtube/comments/route.ts):

          +러 메시지 반환

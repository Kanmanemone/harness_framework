  C. Step 설계

  step 초안을 설계하겠습니다. 문서에 정의된 내용을 기반으로 레이어별로
  분리합니다.

  Step 0: project-setup
    Next.js 15 프로젝트 초기화, Tailwind CSS 4, Vitest 설정, 보일러플레이트 정리

  Step 1: core-types
    types/index.ts — 모든 TypeScript 인터페이스 정의

  Step 2: lib-utils
    lib/youtube.ts, lib/storage.ts, lib/constants.ts + 각각의 단위 테스트

  Step 3: api-youtube
    app/api/youtube/comments/route.ts — YouTube Data API v3 프록시 + 테스트

  Step 4: api-analyze
    app/api/analyze/route.ts — Anthropic Messages API 프록시 + 테스트

  Step 5: service-layer
    services/youtubeService.ts, services/analyzeService.ts + 테스트

  Step 6: ui-atoms
    하위 컴포넌트: SentimentChart, InsightCard, CommentList, ReportHeader,
    EmptyState, ErrorState, LoadingState

  Step 7: ui-containers
    상위 컴포넌트: ApiKeySettings, UrlInput, ReportView

  Step 8: main-page
    app/page.tsx — 상태 관리 + 전체 조립, app/layout.tsx, globals.css

  Step 9: integration-test
    전체 플로우 통합 테스트, 빌드 검증, 엣지 케이스 확인

  설계 근거:
  - Step 0~1은 기반 설정. 이후 step들이 의존하는 타입과 환경.
  - Step 2는 순수 함수 레이어. 외부 의존 없이 테스트 가능.
  - Step 3~4는 API Route 레이어. 각각 독립된 외부 API를 프록시하므로 분리.
  - Step 5는 클라이언트→서버 연결 레이어.
  - Step 6~7은 UI. atoms(props만 받는 표시 컴포넌트)과 containers(상태/이벤트를
  가진 컴포넌트)로 분리.
  - Step 8은 최종 조립.
  - Step 9는 전체 검증.

  이 구성에 대해 피드백이 있으면 말씀해 주세요. 승인하시면 파일을
  생성하겠습니다.

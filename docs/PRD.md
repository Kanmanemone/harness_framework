# PRD: YouTube Comment Analyzer

## 목표
YouTube 영상 URL만 입력하면 댓글을 자동 수집하고 AI로 센티먼트 분석하여, 크리에이터가 시청자 반응을 한눈에 파악할 수 있는 리포트를 생성한다.

## 사용자
YouTube 크리에이터 및 콘텐츠 제작자. 자신의 영상에 대한 시청자 피드백을 빠르게 파악하고 싶은 사람.

## 사전 준비
사용자는 다음 두 가지 API 키를 직접 발급받아야 한다:
1. **YouTube Data API v3 키**: [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 생성 → YouTube Data API v3 활성화 → API 키 발급. 일일 무료 할당량 10,000 유닛 (commentThreads.list 1회 = 1 유닛).
2. **Anthropic API 키**: [Anthropic Console](https://console.anthropic.com/)에서 계정 생성 → API 키 발급. 사용량 기반 과금.

## 핵심 기능

### 기능 1: YouTube URL 입력 및 댓글 수집
YouTube 영상 URL을 입력하면 해당 영상의 댓글을 자동으로 수집한다.

**지원하는 URL 형식:**
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`
- `https://www.youtube.com/v/VIDEO_ID`
- `https://www.youtube.com/shorts/VIDEO_ID`
- 위 형식에 추가 쿼리 파라미터(`&t=`, `&list=`, `&index=` 등)가 붙어도 동작
- `http://` (비보안)도 허용 — `https://`와 동일하게 처리
- URL 앞뒤 공백은 자동으로 trim

**지원하지 않는 입력:**
- 영상 ID만 입력 (예: `dQw4w9WgXcQ`) — URL 형식이 아니므로 거부. 에러 메시지에 올바른 형식 안내 포함.
- 채널 URL, 재생목록 URL — 영상 URL만 지원

**수집 규칙:**
- 최대 100개 댓글 수집 (YouTube API `maxResults` 상한)
- 관련도순(`order=relevance`) 정렬 — 좋아요 많고 답글 많은 의미 있는 댓글 우선
- 최상위 댓글만 수집 (대댓글 제외)
- 일반 텍스트(`textFormat=plainText`) 형식으로 가져옴

**수용 기준:**
- 유효한 YouTube URL 입력 시 댓글이 수집되어야 한다
- 댓글 수집 중 로딩 상태가 UI에 표시되어야 한다
- 수집된 댓글 수와 전체 댓글 수가 리포트 상단에 표시되어야 한다 (예: "100개 댓글 분석 (전체 1,523개 중)")

### 기능 2: AI 센티먼트 분석
수집된 댓글을 Claude AI에 전송하여 센티먼트를 분석한다.

**분석 항목:**
- 전체 요약 (1-2문장)
- 센티먼트 비율: 긍정/중립/부정 퍼센트 (합계 100%)
- 잘하고 있는 점: 최대 5개, 구체적이고 댓글에 근거한 내용
- 개선할 점: 최대 5개, 구체적이고 댓글에 근거한 내용
- 대표 댓글: 긍정/중립/부정 각 2-3개, 원문 인용

**분석 언어:**
- 댓글이 한국어면 분석도 한국어로, 영어면 영어로. 댓글의 주 언어를 따라간다.

**수용 기준:**
- 분석 결과가 JSON 형식으로 파싱 가능해야 한다
- 센티먼트 비율의 합계가 100이어야 한다 (아니면 클라이언트에서 정규화)
- 대표 댓글은 실제 수집된 댓글에서만 인용해야 한다
- 분석 중 로딩 상태가 UI에 표시되어야 한다

### 기능 3: 리포트 표시
분석 결과를 시각적으로 보기 좋은 리포트로 렌더링한다.

**리포트 구성 (위→아래 순서):**
1. 리포트 헤더: 분석된 댓글 수 표시 (예: "100개 댓글 분석 (전체 1,523개 중)")
2. 전체 요약 텍스트
3. 센티먼트 비율 가로 바 차트 (긍정=녹색, 중립=회색, 부정=빨강) + 각 비율 숫자 레이블
4. "잘하고 있는 점" 카드 (불릿 리스트)
5. "개선할 점" 카드 (불릿 리스트)
6. "대표 댓글" 섹션 (센티먼트별 그룹, 각 댓글에 센티먼트 뱃지 + 작성자 표시)
7. 하단: "다른 영상 분석하기" 버튼

**수용 기준:**
- 리포트가 화면에 렌더링되어야 한다
- 리포트가 표시될 때 fade-in 애니메이션이 적용되어야 한다
- "다른 영상 분석하기" 버튼 클릭 시 URL 입력 필드가 비워진 채로 초기 상태로 돌아가야 한다
- 리포트 상태에서도 상단의 URL 입력 필드와 설정 기어 아이콘은 보여야 한다 (다른 영상을 바로 분석할 수 있도록)

### 기능 4: API 키 관리
사용자가 API 키를 입력하고 브라우저에 저장한다.

**동작:**
- 앱 최초 진입 시 API 키가 없으면 설정 패널이 자동으로 열리고, 안내 메시지가 표시된다
- API 키는 localStorage에 저장하여 재방문 시 유지한다
- 설정 패널은 헤더 우측 기어 아이콘으로 접었다 펼 수 있다
- 키 입력 필드는 password 타입으로 마스킹한다
- 키가 저장된 상태에서는 마스킹된 값(예: `sk-ant-...7f3d`)이 표시되어 설정 여부를 확인할 수 있다
- "저장" 버튼 클릭 시 키가 localStorage에 저장되고, 설정 패널이 자동으로 접힌다
- 각 키 옆에 저장 상태 표시: 저장됨(체크마크) / 미설정(빈 상태)
- "키 삭제" 기능: 각 키를 개별적으로 삭제할 수 있다 (localStorage에서 제거)

**온보딩 안내 (설정 패널 내):**
- YouTube API 키 입력란 아래에 짧은 안내: "Google Cloud Console에서 YouTube Data API v3를 활성화하고 API 키를 발급받으세요."
- Anthropic API 키 입력란 아래에 짧은 안내: "Anthropic Console에서 API 키를 발급받으세요."
- 각 안내에 해당 콘솔로의 링크 포함

**수용 기준:**
- API 키를 입력하고 저장하면 localStorage에 저장되어야 한다
- 페이지를 새로고침해도 키가 유지되어야 한다
- 키가 없는 상태에서 분석 버튼을 누르면 에러 메시지가 표시되고 설정 패널이 자동으로 열려야 한다
- 키 삭제 후 해당 키의 상태 표시가 즉시 업데이트되어야 한다

## 사용자 경험 상세

### 빈 상태 (idle, 첫 진입)
앱에 처음 접속하면 다음이 보인다:
- 상단: 앱 제목 "YouTube Comment Analyzer" + 설정 기어 아이콘
- API 키 설정 패널이 자동으로 열려 있음 (키가 없는 경우)
- URL 입력 필드: 플레이스홀더 텍스트 "YouTube 영상 URL을 붙여넣으세요"
- "분석" 버튼 (API 키가 없으면 비활성 상태)
- 입력 영역 아래에 간단한 안내 텍스트: "YouTube 영상의 댓글을 AI로 분석하여 시청자 반응 리포트를 생성합니다."

### 빈 상태 (idle, 재방문 — 키가 있는 경우)
- 설정 패널은 접힌 상태
- URL 입력 필드에 바로 포커스
- "분석" 버튼 활성 상태
- 안내 텍스트 동일

### URL 입력 검증 타이밍
- 실시간 검증 없음 (타이핑 중에 에러를 보여주지 않는다 — UX상 방해됨)
- "분석" 버튼 클릭 시점에 검증 수행
- 검증 실패 시 입력 필드 아래에 인라인 에러 메시지 표시 (빨간색)
- 에러 메시지가 표시된 상태에서 사용자가 입력을 수정하면 에러 메시지 자동 제거

### 로딩 상태
- URL 입력 필드는 유지되지만 수정 불가 (disabled)
- "분석" 버튼이 비활성화되어 중복 클릭 방지
- 입력 영역 아래에 3단계 진행 표시:
  - 각 단계: 아이콘(스피너/체크마크) + 텍스트
  - 현재 단계: 스피너 + 텍스트 (흰색)
  - 완료 단계: 체크마크 + 텍스트 (녹색)
  - 대기 단계: 회색 텍스트

### 에러 상태
- URL 입력 필드에 기존 URL이 그대로 남아 있다 (사용자가 다시 입력하지 않아도 됨)
- "분석" 버튼은 다시 활성화 (바로 재시도 가능)
- 에러 메시지가 카드 형태로 표시: 에러 아이콘 + 메시지 텍스트
- 에러 메시지 아래에 "다시 시도" 버튼 (같은 URL로 재분석)
- API 키 관련 에러인 경우 설정 패널이 자동으로 열림

### 리포트 상태
- URL 입력 필드에 방금 분석한 URL이 남아 있다 (같은 영상 재분석 가능)
- 새 URL을 입력하고 "분석" 버튼을 누르면 기존 리포트가 사라지고 새 로딩 시작
- 리포트 최하단에 "다른 영상 분석하기" 버튼 — 클릭 시 URL 입력 필드 비우고 포커스 이동
- 리포트는 fade-in으로 표시

### 키보드 접근성
- URL 입력 필드에서 Enter 키를 누르면 "분석" 버튼 클릭과 동일하게 동작
- Tab 키로 입력 필드 → 분석 버튼 → 설정 기어 순으로 이동 가능

## 사용자 시나리오

### 시나리오 1: 정상 흐름 (첫 사용)
1. 사용자가 앱에 접속한다
2. API 키가 없으므로 설정 패널이 자동으로 열려 있다
3. 각 키 입력란 아래의 안내 링크를 따라 API 키를 발급받는다
4. YouTube API 키와 Anthropic API 키를 입력하고 "저장" 버튼을 클릭한다
5. 설정 패널이 자동으로 접히고, 분석 버튼이 활성화된다
6. YouTube 영상 URL을 붙여넣고 "분석" 버튼을 클릭한다 (또는 Enter)
7. 로딩 상태가 3단계로 표시된다 (댓글 수집 → 분석 중 → 리포트 생성)
8. 리포트가 fade-in으로 표시된다
9. 리포트를 확인한 뒤 "다른 영상 분석하기" 버튼을 클릭한다
10. URL 입력 필드가 비워지고 포커스가 이동한다

### 시나리오 2: 정상 흐름 (재방문)
1. 사용자가 앱에 재접속한다
2. localStorage에서 API 키를 자동으로 불러온다
3. 설정 패널은 접힌 상태로 시작한다
4. URL 입력 필드에 바로 포커스가 간다
5. YouTube URL을 붙여넣고 Enter 키를 눌러 바로 분석을 시작한다

### 시나리오 3: 연속 분석
1. 첫 번째 영상의 리포트를 확인한다
2. URL 입력 필드에 남아 있는 URL을 지우고 새 URL을 붙여넣는다
3. "분석" 버튼을 클릭한다
4. 기존 리포트가 사라지고 새 로딩이 시작된다
5. 새 리포트가 표시된다

### 시나리오 4: 같은 영상 재분석
1. 리포트가 표시된 상태에서 "분석" 버튼을 다시 클릭한다
2. URL 필드에 같은 URL이 남아 있으므로 동일 영상을 다시 분석한다
3. 새 리포트가 표시된다 (Claude 응답이 매번 약간 다를 수 있음)

### 시나리오 5: 잘못된 URL 입력
1. 사용자가 YouTube가 아닌 URL 또는 잘못된 형식을 입력한다
2. "분석" 버튼 클릭 시 입력 필드 아래에 인라인 에러 "유효한 YouTube URL을 입력해 주세요. (예: https://www.youtube.com/watch?v=...)" 표시
3. API 호출은 발생하지 않는다
4. 사용자가 URL을 수정하면 에러 메시지가 자동으로 사라진다

### 시나리오 6: 영상 ID만 입력
1. 사용자가 URL 없이 영상 ID만 입력한다 (예: `dQw4w9WgXcQ`)
2. "분석" 버튼 클릭 시 인라인 에러 "유효한 YouTube URL을 입력해 주세요. (예: https://www.youtube.com/watch?v=...)" 표시
3. API 호출은 발생하지 않는다

### 시나리오 7: URL에 공백 포함
1. 사용자가 URL 앞뒤에 공백이 포함된 채로 붙여넣는다
2. 입력값이 자동으로 trim 처리된다
3. 정상적으로 분석이 진행된다

### 시나리오 8: 댓글 비활성화 영상
1. 사용자가 댓글이 꺼진 영상의 URL을 입력한다
2. 로딩 1단계(댓글 수집)가 시작된다
3. YouTube API가 403 에러를 반환한다
4. 에러 카드 표시: "이 영상은 댓글이 비활성화되어 있습니다."
5. URL 필드에 기존 URL이 유지되고, 분석 버튼이 활성화된다

### 시나리오 9: 댓글 0개 영상
1. 사용자가 댓글이 없는 영상의 URL을 입력한다
2. 로딩 1단계(댓글 수집) 완료 후 댓글 0개 감지
3. Claude 분석을 호출하지 않고 에러 카드 표시: "이 영상에 댓글이 없습니다."

### 시나리오 10: YouTube API 키 오류
1. 사용자가 잘못된 YouTube API 키를 입력한 상태에서 분석을 시작한다
2. 로딩 1단계 중 YouTube API가 400 에러를 반환한다
3. 에러 카드 표시: "YouTube API 키가 유효하지 않습니다. 키를 확인해 주세요."
4. 설정 패널이 자동으로 열린다

### 시나리오 11: Anthropic API 키 오류
1. YouTube 댓글 수집은 성공했으나, 잘못된 Anthropic API 키로 분석을 시도한다
2. 로딩 2단계 중 Anthropic API가 401 에러를 반환한다
3. 에러 카드 표시: "Anthropic API 키가 유효하지 않습니다. 키를 확인해 주세요."
4. 설정 패널이 자동으로 열린다

### 시나리오 12: API 할당량 초과
1. YouTube API 일일 할당량을 모두 소진한 상태에서 분석을 시작한다
2. YouTube API가 403 + `quotaExceeded` 에러를 반환한다
3. 에러 카드 표시: "YouTube API 일일 할당량을 초과했습니다. 내일 다시 시도해 주세요."
4. 설정 패널은 열리지 않는다 (키 문제가 아니므로)

### 시나리오 13: 비공개/삭제된 영상
1. 사용자가 비공개이거나 삭제된 영상의 URL을 입력한다
2. YouTube API가 404 또는 빈 결과를 반환한다
3. 에러 카드 표시: "영상을 찾을 수 없습니다. URL을 확인해 주세요."

### 시나리오 14: 네트워크 오류
1. 분석 도중 네트워크 연결이 끊긴다
2. fetch가 실패한다
3. 에러 카드 표시: "네트워크 오류가 발생했습니다. 연결을 확인하고 다시 시도해 주세요."
4. "다시 시도" 버튼 클릭으로 동일 URL 재분석 가능

### 시나리오 15: Claude API 응답 파싱 실패
1. Claude가 유효하지 않은 JSON을 반환한다
2. JSON.parse가 실패한다
3. 에러 카드 표시: "분석 결과를 처리하지 못했습니다. 다시 시도해 주세요."
4. "다시 시도" 버튼으로 동일 요청 재시도 가능 (Claude 응답은 비결정적이므로 재시도 시 성공할 수 있음)

### 시나리오 16: Anthropic 잔액 부족
1. Anthropic API 크레딧이 소진된 상태에서 분석을 시도한다
2. Anthropic API가 400 에러를 반환한다
3. 에러 카드 표시: "Anthropic API 잔액이 부족합니다. 크레딧을 확인해 주세요."

### 시나리오 17: API 키 삭제
1. 사용자가 설정 패널에서 Anthropic API 키의 "삭제" 버튼을 클릭한다
2. 해당 키가 localStorage에서 제거된다
3. 키 상태 표시가 "미설정"으로 즉시 변경된다
4. "분석" 버튼이 비활성화된다 (두 키 모두 필요)

### 시나리오 18: localStorage 접근 불가 (시크릿 모드)
1. 사용자가 시크릿/프라이빗 브라우징 모드에서 앱에 접속한다
2. localStorage 접근이 실패한다
3. 앱은 정상 동작하지만 키가 세션 중에만 메모리에 유지된다
4. 페이지를 닫으면 키가 사라지고, 재접속 시 다시 입력해야 한다
5. 설정 패널에 안내: "시크릿 모드에서는 API 키가 저장되지 않습니다."

## 제약사항
- 댓글 수집 상한: 100개 (YouTube API `maxResults` 최대값이 100이며, 비용과 분석 품질의 균형점)
- Claude 컨텍스트: 100개 댓글은 약 10,000~30,000 토큰. Sonnet의 입력 한도(200K) 내에서 충분히 처리 가능
- Claude 응답 제한: `max_tokens: 2048` (리포트 JSON에 충분한 크기)
- YouTube API 일일 할당량: 10,000 유닛 (무료 티어). 1회 분석 = 1 유닛이므로 하루 최대 ~10,000회 분석 가능
- localStorage 용량: API 키 2개 저장에 ~200바이트. 브라우저 localStorage 한도(5MB)와 무관
- 분석 소요 시간: YouTube API 응답 ~1-3초 + Claude 응답 ~5-15초. 사용자에게 총 10-20초 정도의 대기 예상

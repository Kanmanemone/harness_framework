# PRD: YouTube Comment Analyzer

## 목표
YouTube 영상 URL만 입력하면 댓글을 자동 수집하고 AI로 센티먼트 분석하여, 크리에이터가 시청자 반응을 한눈에 파악할 수 있는 리포트를 생성한다.

## 사용자
YouTube 크리에이터 및 콘텐츠 제작자. 자신의 영상에 대한 시청자 피드백을 빠르게 파악하고 싶은 사람.

## 핵심 기능
1. YouTube URL 입력 → 영상 댓글 자동 수집 (최대 100개, 관련도순)
2. Claude AI를 활용한 댓글 센티먼트 분석 (긍정/중립/부정 비율)
3. 분석 리포트 표시: 전체 요약, 센티먼트 비율 차트, 잘하고 있는 점(최대 5개), 개선할 점(최대 5개), 대표 댓글 인용

## MVP 제외 사항
- 로그인/회원가입 기능
- 데이터베이스 및 분석 히스토리 저장
- 다국어 UI (분석 결과는 댓글 언어에 맞춰 자동 대응)
- 여러 영상 비교 분석
- 댓글 시간대별 추이 분석

## 디자인
- 다크모드 고정, 미니멀
- 무채색 기반 + 센티먼트 표시용 시맨틱 색상 (녹색=긍정, 빨강=부정, 회색=중립)
- 단일 페이지 구성 (입력 → 로딩 → 리포트 상태 전환)
